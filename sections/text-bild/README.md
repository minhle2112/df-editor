# Section `text-bild`

Text block next to an image (Text & Bild).

## Variants
| Key | Label (DE) |
|---|---|
| `image-left` | Bild links |
| `image-right` | Bild rechts |

On mobile the image is always above the text.

## Options
| Key | Values | Default | Notes |
|---|---|---|---|
| `ratio` | `50-50`, `40-60` | `50-50` | `40-60`: the image takes 40 % |
| `image_style` | `plain`, `rounded`, `shadow` | `rounded` | |
| `heading_level` | `h2`, `h3` | `h2` | |
| `show_button` | `yes`, `no` | `yes` | |
